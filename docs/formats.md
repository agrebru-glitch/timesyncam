# Камеры и форматы

## Откуда берётся время

Программа проверяет источники по порядку надёжности и берёт первый найденный.

| Источник | Камеры | Что даёт |
|---|---|---|
| XML рядом с клипом (`C0001M01.XML`) | Sony | Тайм-код с частотой счёта, время начала с часовым поясом, частота съёмки (S&Q), модель, объектив, гамма |
| Дорожка тайм-кода в файле (`tmcd`, `rtmd`) | Canon, Panasonic, Fujifilm, Nikon, Blackmagic, Sony | Тайм-код, в том числе drop frame для 29,97 и 59,94 |
| Дата съёмки с часовым поясом | iPhone (`com.apple.quicktime.creationdate`) | Время с поясом |
| Время в имени файла | DJI (`DJI_20260612183015_0001_D.MP4`), Android и Pixel (`PXL_…`, `VID_…`) | Местное время начала, до секунды или миллисекунды |
| Время создания в файле (`creation_time`) | Большинство камер | Время начала. GoPro и часть DJI пишут местное время с пометкой UTC — программа читает его как местное |
| BWF в WAV | Рекордеры Zoom, Tascam, Sound Devices, Zaxcom и другие | Тайм-код (`time_reference`), дата и время записи |
| Дата изменения файла | Всё остальное | Конец записи. Надёжна, только если карту копировали без пересохранения |

## Кодеки и контейнеры

Всё, что читает FFmpeg: H.264, H.265, ProRes, DNxHD/HR, MPEG-2, AV1, VP9, CineForm, Motion JPEG, несжатое видео; контейнеры MP4, MOV, MXF, MTS/M2TS, MKV, AVI. Звук — WAV/BWF и звуковые дорожки видеофайлов.

**Пока не читаются**: BRAW, R3D, Canon RAW (CRM), ARRIRAW. Их нужно перегнать в ProRes или H.264/H.265 с сохранением тайм-кода, например в DaVinci Resolve. Программа покажет, сколько таких файлов нашлось в папке.

## Прокси

Встроенный плеер проигрывает H.264 8 бит 4:2:0. Оригиналы 4:2:2 10 бит, ProRes и MXF показываются стоп-кадрами через FFmpeg. Чтобы предпросмотр шёл видео, программа ищет прокси рядом с клипами:

| Камера или программа | Где лежат прокси |
|---|---|
| Sony | Папка `SUB`, файлы `C0001S03.MP4` |
| GoPro | Файлы `.LRV` рядом с клипами |
| DJI | Файлы `.LRF` рядом с клипами |
| DaVinci Resolve и другие | Папка `Proxy` / `Proxies` рядом с клипами, то же имя файла |

## Если камера читается неправильно

Создайте задачу «Поддержка камеры» и приложите вывод команды:

```bash
ffprobe -v error -show_format -show_streams -of json "клип.mp4"
```

и XML-файл рядом с клипом, если он есть. Это текст без изображения, но в нём могут быть серийный номер камеры и координаты GPS — удалите их перед публикацией.
