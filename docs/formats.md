# Камеры и форматы

## Откуда берётся время

Программа проверяет источники по порядку надёжности и берёт первый найденный.

| Источник | Камеры | Что даёт |
|---|---|---|
| XML рядом с клипом (`C0001M01.XML`) или тот же XML внутри MP4 | Sony | Тайм-код с частотой счёта, время начала с часовым поясом, частота съёмки (S&Q), модель, объектив, гамма. Если XML рядом потерялся, программа берёт его копию из самого MP4 |
| Дорожка тайм-кода в файле (`tmcd`, `rtmd`) | Canon, Panasonic, Fujifilm, Nikon, Blackmagic, Sony | Тайм-код, в том числе drop frame для 29,97 и 59,94 |
| Дата съёмки с часовым поясом | iPhone (`com.apple.quicktime.creationdate`) | Время с поясом |
| Время в имени файла | DJI (`DJI_20260612183015_0001_D.MP4`), Android (`VID_…`, `20260612_183015.mp4`), Pixel (`PXL_…`) | Время начала, до секунды или миллисекунды: местное, у Pixel — по UTC |
| Время создания в файле (`creation_time`) | Большинство камер | Время начала. GoPro и часть DJI пишут местное время с пометкой UTC — программа читает его как местное. Часть телефонов Android пишет момент остановки записи — программа видит это по времени в имени файла или по записям того же телефона, совпавшим по звуку |
| BWF в WAV | Рекордеры Zoom, Tascam, Sound Devices, Zaxcom и другие | Тайм-код (`time_reference`), дата и время записи |
| Дата изменения файла | Всё остальное | Конец записи. Надёжна, только если карту копировали без пересохранения |

Время в файлах камер записано с точностью до секунды, тайм-код — до кадра. Точное место клипа даёт только сверка по звуку, метаданные — подсказка: какие клипы — одна запись, какое время суток, где стоят клипы без звука.

Если звук в файле начинается позже видео (так пишут часть телефонов: у realme — на 0,2 с), программа отсчитывает его от начала клипа, как и монтажка.

## Кодеки и контейнеры

Всё, что читает FFmpeg: H.264, H.265, ProRes, DNxHD/HR, MPEG-2, AV1, VP9, CineForm, Motion JPEG, несжатое видео; контейнеры MP4, MOV, MXF, MTS/M2TS, MKV, AVI. Звук — WAV/BWF (в том числе RF64 и W64 для записей больше 4 ГБ), M4A (AAC, ALAC), MP3, MP2, AAC, FLAC, AIFF, CAF, OGG/Opus, WMA, AC3/E-AC3, DTS, AMR, WavPack, APE, MKA и звуковые дорожки видеофайлов. Папку можно перетащить целиком, а можно — отдельные файлы.

**Пока не читаются**: BRAW, R3D, Canon RAW (CRM), ARRIRAW. Их нужно перегнать в ProRes или H.264/H.265 с сохранением тайм-кода, например в DaVinci Resolve. Программа покажет, сколько таких файлов нашлось в папке.

## Прокси

Встроенный плеер проигрывает H.264 8 бит 4:2:0. Оригиналы 4:2:2 10 бит, ProRes и MXF показываются стоп-кадрами через FFmpeg. Чтобы предпросмотр шёл видео, программа ищет прокси рядом с клипами:

| Камера или программа | Где лежат прокси |
|---|---|
| Sony | Папка `SUB`, файлы `C0001S03.MP4` |
| GoPro | Файлы `.LRV` рядом с клипами |
| DJI | Файлы `.LRF` рядом с клипами |
| DaVinci Resolve и другие | Папка `Proxy` / `Proxies` рядом с клипами, то же имя файла |

## Если камера читается неправильно

Проще всего — расширенный отчёт: вкладка «Замечания» → «Сохранить расширенный отчёт». В архиве звук клипов без видео, сведения о файлах и устройство каждого файла MP4/MOV — где камера хранит время и тайм-код. Координат съёмки и серийных номеров в нём нет.

Или создайте задачу «Поддержка камеры» и приложите вывод команды:

```bash
ffprobe -v error -show_format -show_streams -of json "клип.mp4"
```

и XML-файл рядом с клипом, если он есть. Это текст без изображения, но в нём могут быть серийный номер камеры и координаты GPS — удалите их перед публикацией.
