TCoder

версия · экран синхронизации для TimesynCam

TCoder показывает QR-код с точным временем телефона. Камеры снимают его — и программа TimesynCam на компьютере ставит их клипы на таймлинию с точностью до четверти кадра, даже без общего звука и тайм-кода.

Настройка камер

Как снимать экран синхронизации
  1. В настройках телефона включите дату и время сети — QR-код показывает время телефона.
  2. Откройте TCoder: яркость сама встанет на максимум, экран не погаснет.
  3. Снимите экран каждой камерой 5–10 секунд, чтобы QR-код был целиком в кадре и в фокусе. Можно до съёмки, после или в перерыве — время зашито в самом коде, снимать одновременно не нужно.
  4. Не выключайте камеру без тайм-кода между съёмкой экрана и событием: поправка переносится на все её клипы.
  5. В TimesynCam: правая кнопка по клипу, где виден экран, → «Выбрать контрольным кадром», затем «Синхронизировать» → «Контрольный кадр + тайм-код + звук».

Не прочиталось — чаще всего блик на экране, смаз или слишком мелкий код в кадре.

Часы на всех камерах

Одинаковые дата, время и часовой пояс, с точностью до секунды. Удобно выставлять по телефону: подготовьте время на минуту вперёд и подтвердите ровно в начале минуты. Во время съёмки часы не трогайте.

Sony: MENU → Настройка → Регион/дата/время.

Тайм-код: Free Run и Preset

TC/UB → Time Code Run → Free Run. В Rec Run паузы между клипами пропадают, и точность падает до секунды.

Time Code Make → Preset, в Time Code Preset — примерно текущее время суток. До кадра совпадать не обязательно.

User Bit Time Rec → Вкл. — запасное время по часам камеры.

Звук на каждой камере

Держите встроенный микрофон камеры включённым, даже если основной звук пишется отдельно: по нему TimesynCam сверяет камеры между собой. Проверьте, что запись звука включена и уровень не на нуле.

Canon, Panasonic, Fujifilm, Nikon, Blackmagic

Тайм-код — Free Run, по текущему времени, если камера это умеет. Часы — по одному источнику. Камеры с входом тайм-кода подключайте к генератору — они станут опорными.

GoPro, DJI, телефоны

Время на экшн-камерах выставляется с телефона при подключении к приложению (GoPro Quik, DJI Fly / Mimo) — подключите каждую камеру перед съёмкой. Часы телефонов сверяются с сетью и обычно точны.

Рекордеры звука

Zoom, Tascam, Sound Devices пишут WAV с меткой времени. Выставьте на рекордере те же часы, что и на камерах.

Копируйте карту целиком

Вместе с файлами C0001M01.XML рядом с клипами — в них время съёмки и тайм-код. Не переименовывайте клипы. Каждая камера — в свою папку.
