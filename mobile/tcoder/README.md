# TCoder — экран синхронизации на Android

TCoder — маленькое Android-приложение-спутник TimesynCam. Оно показывает тот же **экран синхронизации**, что и программа на компьютере: QR-код с точным временем, который меняется каждую секунду. Камеры снимают телефон 5–10 секунд, и TimesynCam ставит их клипы по контрольному кадру. Удобно, когда ноутбука с программой на площадке нет.

Сделано 2026-11-02, выпускать — **вместе с релизом TimesynCam 0.4.0** (APK — файлом в релизе на GitHub).

## Что внутри

- **Первый экран — экран синхронизации**: белый фон, QR-код `TSC1 <мс эпохи>` (формат и период — из `src/core/qrSync.ts`, общего с десктопом), часы под ним, короткая подсказка. Яркость на максимум и экран не гаснет, пока виден QR-код; полноэкранный режим. Работает и в горизонтальной ориентации.
- **Кнопка ⓘ → «О программе»**: значок и версия, «Поддержать проект» (CloudTips), «TimesynCam на GitHub», FAQ по настройке камер (сжатый из `src/renderer/components/FaqPage.tsx`). Тёмная тема и значки — из десктопа. «Назад» телефона возвращает к QR-коду.
- Время в QR-коде — **часы телефона**: в FAQ первым пунктом — включить «Дату и время сети». Взаимное положение камер, снявших один экран, точно в любом случае; от часов телефона зависит только время суток.

| Файл | Что это |
|---|---|
| `AndroidManifest.xml` | пакет `com.timesyncam.tcoder`, minSdk 24, targetSdk 34, без разрешений |
| `java/com/timesyncam/tcoder/MainActivity.java` | WebView со страницей; не гасить экран, яркость (мост `TCoder.bright`), ссылки — в браузере |
| `web/index.html`, `web/style.css`, `web/app.ts` | вся страница: экран синхронизации и «О программе» |
| `scripts/build-tcoder.mjs` | сборка APK |

Значок — `build/icon.png` десктопа, при сборке нарезается под все плотности экрана (`ffmpeg`). В About вставляется `build/icon.svg`.

## Сборка

```bash
npm run dist:tcoder
```

Результат — `release/TCoder-<версия из package.json>.apk`. Без Gradle и без скачиваний: esbuild собирает страницу, дальше инструменты Android SDK — `aapt2` (ресурсы, манифест), `javac --release 11`, `d8`, `aapt add`, `zipalign`, `apksigner`.

Нужны: Android SDK (`ANDROID_HOME` или `%LOCALAPPDATA%\Android\Sdk`) с build-tools и `platforms/android-34`; JDK (`JAVA_HOME` или Java из Android Studio — `jbr`); `ffmpeg` в PATH. Номер версии: 0.4.0 → 400, 1.2.3 → 10203.

Проверено 2026-11-02 в эмуляторе (Medium Phone, API 37): QR-код со снимка экрана читается декодером TimesynCam (`jsqr`) как `TSC1 <время телефона>`, About открывается, «Назад» возвращает к QR-коду.

## Перед выпуском с 0.4.0

1. **Ключ подписи для релиза.** Сейчас без настроек APK подписан отладочным ключом `~/.android/debug.keystore` — для теста годится, для публикации нет: обновления должны подписываться одним и тем же ключом всегда. Создать один раз и хранить вне репозитория (с резервной копией):
   ```bash
   keytool -genkeypair -v -keystore tcoder-release.jks -alias tcoder -keyalg RSA -keysize 4096 -validity 10000
   ```
   Сборка с ним: `TCODER_KEYSTORE=путь\tcoder-release.jks`, `TCODER_KEYSTORE_PASS=пароль`, при другом псевдониме — `TCODER_KEY_ALIAS`. **Ключ и пароль в репозиторий не класть.**
2. Версия берётся из `package.json` — при выпуске 0.4.0 будет `TCoder-0.4.0.apk`.
3. Приложить APK к релизу на GitHub; в README и FAQ десктопа добавить ссылку («Экран синхронизации на телефоне — TCoder»).
4. Google Play — по желанию позже: там нужен AAB и targetSdk по их текущим требованиям.
